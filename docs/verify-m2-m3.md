# M2 / M3 验证清单

验收标准见 [milestones.md](milestones.md)。`npm test` 只覆盖接口和 mock AI，这份清单检查自动测试覆盖不到的部分：真实 AI 的输出、页面操作、实际下载和真实日志频道。

## 准备

```bash
npm run build
```

```bash
DEV_LOGIN=1 PORT=8788 DATA_DIR=data/verify npm start
```

打开 <http://localhost:8788>，在登录页选账号，换人时先退出登录。

- **账号**：A = Alice Chen，B = Bob Li，管理员 = Carol Wu。
- **数据**：全部写入 `data/verify`，不影响 `data/glaucus.db`。首次启动会自动放入示例笔记。
- **外部调用**：会调用真实 LLM（有少量费用），也会往真实日志频道发消息，包括启动时的 `🟢 Glaucus started`。这是第 12、13、15、17 步要检查的内容，如果频道里有其他人，可以先打个招呼。
- **安全**：`DEV_LOGIN=1` 时任何人都能以管理员身份登录，只在本机运行，用完就关。

结束后清理：

```bash
rm -rf data/verify
```

## 素材

准备 2 张图片和 1 个 PDF，正文粘贴：

```text
今天调 intake。compliant 轮测了 10 次成功 9 次，REV 轮 10 次成功 6 次，决定用 compliant 轮。
电机功率 0.8 时零件会被甩出去，改成 0.6 后没再发生。下次把轮子间距改小再测。
```

## M2：录入与草稿

| # | 账号 | 操作 | 预期 |
|---|---|---|---|
| 1 | A | New note，粘贴正文，传 2 张图和 PDF，日期不改，提交 | 日期默认今天；进入生成中，不用刷新就能看到草稿 |
| 2 | A | 查看草稿 | 左边是原始素材，右边是表单；内容为英文；9/10、6/10、0.8、0.6 都和素材一致 |
| 3 | A | 找素材里没有的内容 | 素材没提到时间时，开始和结束时间留空；其他缺失项标 `[needs input]`；没有编造的数字或型号 |
| 4 | A | 手改标题，保存，刷新 | 修改还在 |
| 5 | A | 改一条图片说明，调整图片顺序，保存，刷新 | 修改都还在 |
| 6 | A | 让 AI 改稿：`Add a next step: retest at 0.6 power` | 生成时表单只读；只多了这一条，其他内容（包括第 4 步的标题）不变；刷新后还在 |
| 7 | A | Regenerate | 先弹确认框，确认后得到新草稿 |
| 8 | A | 同一条笔记开两个标签页，先在第一个保存，再在第二个保存 | 第二个提示冲突，不会静默覆盖 |

## M3：批准与归档

| # | 账号 | 操作 | 预期 |
|---|---|---|---|
| 11 | A | 第 1 条笔记点 Submit for review | 状态变为待批准；A 不能点 Approve，并有原因提示 |
| 12 | A | 待批准时编辑并保存，然后重新提交 | 先弹确认框；保存后回到草稿，重新提交后再次待批准；频道收到两次 📨 |
| 13 | B | 不填理由尝试 Return，再填理由提交 | 没有理由时退回不了；有理由时回到草稿并显示理由；频道收到 ↩️ |
| 14 | A | 修改后重新提交 | 退回提示消失，状态变为待批准 |
| 15 | B | Approve | 状态变为已归档；频道收到 ✅ |
| 16 | A | 打开已归档笔记 | 只读，没有编辑入口 |
| 17 | 管理员 | 改一个字段并保存，打开 Revision history | 先弹确认框；修订历史里能看到旧值；频道收到 ✏️ |
| 18 | A | 在详情页点 Export .md | 下载 `日期-slug.md`，内容是第 17 步修改后的版本 |
| 19 | A | 在列表选 2 条以上已归档笔记，点 Export zip，解压 | 有 `entries/*.md` 和 `assets/<日期>/*.jpg`；`.md` 里的图片相对路径能打开 |
| 20 | 任意 | 复制一张图片的地址，在无痕窗口打开 | 被拒绝（401） |
